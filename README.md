# 📦 Inventory Management System

A **console-based Inventory Management System** built using **C++ OOP concepts**.  
It helps track products, quantities, and prices efficiently using **classes**, **vectors**, and **file handling (CSV)**.

---

## 🚀 Features

- Add new products to the inventory  
- View all available products  
- Update product quantity and price  
- Delete products from the system  
- Search products by name  
- Save and load data from a CSV file for persistence  

---

## 🧠 Concepts Used

- Object-Oriented Programming (Classes, Objects, Encapsulation)  
- STL Vector for dynamic storage  
- File Handling (CSV input/output)  
- Basic CRUD operations (Create, Read, Update, Delete)

---

## 🧰 Technologies

- **Language:** C++  
- **Compiler:** g++ (C++17 or higher)  
- **IDE:** VS Code / Code::Blocks / Any C++ IDE
